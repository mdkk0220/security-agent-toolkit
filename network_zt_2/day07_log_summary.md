# 정산 포털 정책 로그 점검 결과

## 결론
- 거부하기로 정한 요청 중 실제로는 통과된 건이 있었고, 판단 기록을 거치지 않은 접속도 확인되었습니다. 정상 업무 요청이 자주 추가 확인을 받는 문제도 있었습니다.

## 근거
- 요청 101(02:14, seoyeon): 거부하기로 기록됐지만 앱은 응답 번호 200으로 처리했습니다. 전체 12건 중 판단과 앱 처리가 다른 요청은 3건입니다.
- 요청 201(12:34, seoyeon): 판단 기록에는 없지만 앱 기록에는 응답 번호 200으로 남아 있습니다.
- 현재 규칙은 정상 요청 오탐 6건, 위험 요청 미탐 0건입니다. 대량 조회 기준을 50건으로 올린 안 A는 오탐 0건, 미탐 1건입니다.

## 권고
- 거부 결정이 앱에서 그대로 적용되는지 요청을 먼저 받는 곳의 설정과 처리 순서를 점검합니다. 요청 101이 통과된 원인은 현재 기록만으로 알 수 없으므로 앱 처리 기록과 오류 기록을 확인합니다.
- 대량 조회 기준을 50건으로 올리는 안 A를 적용하되, 해외에서 49건 이하를 조회하는 위험 요청을 놓치지 않도록 해외 접속 등 다른 위험 신호도 함께 확인합니다.
