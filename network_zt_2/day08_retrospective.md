# 2과목 회고 (10/21(수))
## 잘 이해한 것
- Docker 포트 바인딩(`127.0.0.1` 과 `0.0.0.0`), `docker ps` 와 `docker logs` 를 함께 써서 서버 장애 원인을 찾는 방법, 정책 로그에서 거부 후 허용을 찾고 새 자료에 따라 판단을 정정하는 방법을 익혔다.
## 막힌 것
- 처음에는 Windows 환경에서 macOS용 `ipconfig getifaddr en0` 을 실행했고, 컨테이너 이름이 없거나 명령 앞에 오타가 있어 확인이 실패했다. 실제 LAN 주소와 로컬 주소를 구분해 접속 여부를 검증하고, 실행 결과가 없는 항목은 추정과 관측 사실을 구분해 적는 연습이 더 필요하다.
## 3과목과 캡스톤에서 이어 갈 것
- `day06_zt_scenario.md` 의 Zero Trust 적용 방안·최소권한 기준과 `day08_issue_diagram.md` 의 로그 근거·가설·조치 흐름을 RBAC 정책 설계와 캡스톤의 보안 자세 점검에 활용하고 싶다.
