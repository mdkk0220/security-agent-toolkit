### 문제 2-1 · 새벽 대량 조회 사건 추적하고 단정할 수 있는지 따지기

- (가) 의심스러운 접근 기록은 몇 번이고, 이상해 보이지만 정상인 줄은 몇 번인가요? 한 줄씩은 정상 같지만 모아서 보면 이상한 줄이 있으면 함께 적어 주세요.
  - 쓸 내용: 「의심: 번호 … / 이상해 보이지만 정상: 번호 … (정상으로 본 이유) / 모으면 이상한 줄: 번호 … (이유)」
  - 답: 의심스러운 줄은 2·3·4·5번입니다. 영업팀 seoyeon이 새벽에 등록되지 않은 기기에서 정산 내역을 조회했습니다. 1번은 새벽에 320건을 조회해 이상해 보이지만, 매일 02:00에 정산을 집계하는 서비스 계정 `batch-night`가 등록 기기 `SRV-BATCH`에서 실행한 작업이라 정상입니다. 12·14·15·16·17번은 한 줄씩 보면 정상 기기와 MFA 로그인이고, 한 번의 조회량도 평소 범위지만, seoyeon이 맡은 자원이 아닌 `SETTLE`을 반복 조회해 총 95건을 본 점에서 모으면 이상합니다.
- (나) 🔍 의심스러운 줄의 근거 필드는 무엇인가요? 필드마다 등록 정보나 같은 계정의 다른 줄과 어떻게 다른지 적어 주세요.
  - 쓸 내용: 근거 필드 세 가지 이상, 필드마다 「어떤 값이 어떤 값과 다른지」
  - 답: 기기는 2번부터 5번까지의 `NB-7741`이 등록 정보에 없고, seoyeon의 등록 기기는 `NB-0417`입니다. 시각은 2번부터 5번까지가 02:14에서 02:15 사이로, 같은 계정의 다른 활동 시간대인 10:40에서 18:10 사이와 다릅니다. 자원은 2번부터 5번까지 `SETTLE`을 조회했지만 seoyeon이 맡은 자원은 `SALES`이며, 정상적인 9·11·18번은 `SALES`를 조회했습니다. 건수는 40건씩 세 번으로 총 120건입니다. 로그인 방식은 2번이 비밀번호만(`pw`)이고, 같은 계정의 정상 로그인 8번은 비밀번호와 MFA를 사용했습니다. 출발 IP도 새벽 기록은 `10.20.5.77`, 낮의 정상 기록은 `10.20.4.21`입니다.
- (다) 🔍 방화벽이 막지 못하고 통과한 이유를 5대 원칙의 어느 칸이 비어 있었는지로 설명해 주세요.
  - 쓸 내용: ① 비어 있던 칸 두 개 이상 ② 칸마다 확인했어야 할 것
  - 답: 기록의 출발 IP가 모두 A사 사내 대역 `10.20.`으로 시작해 경계 방화벽을 통과했지만, 방화벽은 등록 기기·업무 권한·시간과 조회량을 확인하지 않았습니다. 2번부터 5번까지는 Device 칸에서 기기 `NB-7741`의 등록 여부와 보안 상태를, ID 칸에서 비밀번호 외에 MFA를 확인했어야 합니다. Application 칸에서는 seoyeon에게 `SETTLE` 조회 권한이 있는지, Policy 칸에서는 새벽의 반복·대량 조회에 추가 인증이나 차단이 필요한지 확인했어야 합니다. 12번과 14번부터 17번까지도 Application에서 맡은 자원인지, Policy에서 반복 조회 건수를 합산하는지 확인하지 못했습니다.
- (라) 🔍 이 기록만으로 「seoyeon 계정이 도용됐다」고 단정할 수 있나요? 기록으로 확인된 것과 확인하지 못한 것, 그것을 확인하려면 볼 자료를 적어 주세요.
  - 쓸 내용: ① 단정할 수 있는지 ② 기록으로 확인된 것 ③ 확인하지 못한 것 ④ 확인하려면 볼 자료
  - 답: 이 기록만으로 계정 도용이라고 단정할 수 없습니다. 확인된 사실은 02:14에 등록되지 않은 기기 `NB-7741`에서 seoyeon 계정이 비밀번호만으로 로그인해 `SETTLE` 120건을 조회했고, 낮에도 정상 로그인 뒤 맡은 자원이 아닌 `SETTLE`을 19건씩 다섯 번, 총 95건 조회했다는 것입니다. 하지만 실제 사용자가 seoyeon 본인인지, 비밀번호가 도용됐는지, 낮 조회가 업무상 정당했는지는 기록만으로 알 수 없습니다. seoyeon 본인과 팀장에게 확인하고, 기기 등록·구매 기록, `10.20.5.77`이 연결된 위치를 보여 주는 네트워크 장비 기록, 업무 요청 기록과 `SETTLE` 권한 부여 기록을 확인해야 합니다.
- (한 줄) 보안 담당에게 보낼 답을 한 문장으로 적어 주세요.
  - 쓸 내용: 보안 담당이 바로 읽을 수 있는 한 문장(무슨 일이 있었고 무엇을 더 확인해야 하는지)
  - 답: 등록되지 않은 기기에서 seoyeon 계정으로 새벽에 정산 내역 120건이 조회되고 낮에도 맡은 자원이 아닌 정산 내역 95건이 반복 조회됐으므로, 계정 도용으로 단정하기 전에 본인·기기 소유자·업무 요청 및 권한 기록을 확인해야 합니다.

### 문제 2-2 · 접속 요청 여섯 개를 5대 원칙의 칸으로 분류하기

- (가) 요청 ① ~ ⑥ 은 각각 5대 원칙 중 어느 칸에서 걸리나요? 걸리지 않고 통과하면 「통과」라고 적어 주세요.
  - 쓸 내용: 「①: … / ②: … / ③: … / ④: … / ⑤: … / ⑥: …」 여섯 개
  - 답: ① ID에서 걸립니다. 관리자 계정이 비밀번호만 사용하고 MFA를 하지 않았습니다. ② Device에서 걸립니다. 개인 노트북의 백신이 꺼져 있고 패치가 6개월 동안 적용되지 않았습니다. ③ Application에서 걸립니다. 마케팅팀 사용자에게 인사 시스템 앱 권한이 없습니다. ④ Network에서 걸립니다. 앱을 통하지 않고 서버 구역의 DB에 직접 연결하려 합니다. ⑤ Policy에서 걸립니다. 평소 서울에서만 접속하던 사용자가 새벽 3시에 해외 IP로 접속했습니다. ⑥ 통과합니다. 계정과 MFA, 회사 노트북 상태, 영업 앱 권한, 위치와 시간이 정상입니다.
- (나) 🔍 요청 ⑤ 는 ID · Device · Application 이 모두 정상인데 왜 Policy 칸에서 걸리나요?
  - 쓸 내용: ① 정상인 것 ② 평소와 달라진 상황 ③ Policy 칸이 하는 일
  - 답: 요청 ⑤는 비밀번호와 MFA를 사용하고, 최신 상태의 회사 노트북을 사용하며, 영업팀의 권한 있는 영업 앱에 접속하므로 ID, Device, Application은 정상입니다. 하지만 평소 서울에서만 접속하던 사용자가 새벽 3시에 해외 IP로 접속한 점이 평소와 다릅니다. Policy는 시간과 위치 같은 상황을 살펴 추가 인증을 요구하거나 접근을 막습니다.
- (다) 요청 ③ 과 ④ 는 둘 다 가면 안 되는 곳에 닿으려는 시도인데 왜 서로 다른 칸에서 걸리나요?
  - 쓸 내용: ① ③ 이 확인하는 것 ② ④ 가 확인하는 것
  - 답: ③은 Application에서 걸립니다. 마케팅팀 사용자가 인사 시스템 앱을 쓸 권한이 있는지 확인하는 문제이고, 이 사용자에게는 권한이 없습니다. ④는 Network에서 걸립니다. 앱 권한이 아니라 서버 구역의 DB에 직접 닿을 수 없도록 네트워크 경로와 구역 사이 통신을 제한하는 문제입니다.
- 이 교시에서 새로 알게 된 것 하나를 적어 주세요.
  - 쓸 내용: 자유롭게
  - 답: 요청마다 ID, 기기, 네트워크, 앱 권한, 접속 상황을 나누어 확인해야 하며, 앱 권한 문제와 네트워크 경로 문제는 서로 다른 통제에서 막는다는 것을 알게 됐습니다.

## 3교시 · 점수로 판단하는 함수 (PDP)

### 문제 3-1 · 권한 변경 판단 함수의 점수 직접 정하기

- (가) 내가 채운 코드 여덟 줄을 붙여 넣어 주세요.
  - 쓸 내용: `# ←` 여덟 곳에 채운 코드(점수 세 개 · 역할 검사 두 줄 · MFA 점수 블록 세 줄)
  - 답:

```
HEALTH_POINTS = 50
MFA_POINTS = 30
COUNTRY_POINTS = 40

    if account["role"] != "account_admin":
        return "거부", ["관리자 역할이 아님"]

    if req["mfa"] == False:
        score = score + MFA_POINTS
        reasons.append("MFA 안 함")
```

- (나) 🔍 실행해서 나온 요청 A ~ F 의 결정을 적어 주세요. 모두 기대 결정과 같은지도 함께 적어 주세요.
  - 쓸 내용: 「A: … / B: … / C: … / D: … / E: … / F: …」 여섯 개와 「기대 결정과 같음 · 다름」
  - 답: A: 허용(`[]`) / B: 거부(`관리자 역할이 아님`) / C: 추가확인(`MFA 안 함`) / D: 거부(`기기 보안 상태 이상`) / E: 추가확인(`해외에서 접속`) / F: 거부(`MFA 안 함`, `해외에서 접속`). 여섯 요청 모두 기대 결정과 같습니다.
- (다) 🔍 점수 세 개를 정하면서 찾은 조건을 적어 주세요. 점수 하나가 가질 수 있는 범위와, 두 점수의 합이 만족해야 하는 조건이 있나요?
  - 쓸 내용: ① 기기 보안 상태 이상 점수의 범위 ② MFA 점수와 해외 점수의 범위 ③ 둘의 합이 만족해야 하는 조건과 그 이유(요청 몇 번 때문인지)
  - 답: 결정 기준은 50점 이상이면 거부, 10점 이상이면 추가확인입니다. D는 기기 보안 상태 이상만으로 거부되어야 하므로 기기 점수는 50점 이상이어야 합니다. C와 E는 각각 MFA 미실시와 해외 접속만으로 추가확인이어야 하므로 MFA 점수와 해외 점수는 각각 10점 이상 50점 미만이어야 합니다. F는 두 신호가 함께 있는 요청이므로 MFA 점수와 해외 점수의 합이 50점 이상이어야 거부됩니다. 예를 들어 기기 50점, MFA 30점, 해외 40점으로 정하면 C와 E는 추가확인, D와 F는 거부됩니다.
- (라) 🔍 기기 보안 상태 이상은 정산 조회에서는 추가확인인데 권한 변경에서는 거부입니다. 왜 기준이 다른가요?
  - 쓸 내용: ① 정산 조회에서 그 신호의 점수와 결정 ② 내가 정한 권한 변경 점수와 결정 ③ 기준이 다른 이유
  - 답: 정산 내역 조회에서는 기기 보안 상태 이상에 40점이 더해져 추가확인됩니다. 권한 변경에서는 같은 신호에 50점을 주어 거부되도록 정했습니다. 권한 변경은 계정 권한을 바꿀 수 있어 조회보다 영향이 크므로, 이 작업에는 더 엄격한 기준을 적용해 위험한 요청을 차단합니다.

### 문제 3-2 · 요청 7건을 한꺼번에 판정해 건수 세기

- (가) 실행해서 나온 출력 전체를 붙여 넣어 주세요.
  - 쓸 내용: 거부 · 추가확인 줄, 건수 줄, 이유별 건수 줄 전체
  - 답:

```
[추가확인] 2 seoyeon ['대량 조회 (+30)']
[거부] 3 seoyeon ['이 계정에 등록된 기기가 아님']
[거부] 4 dami ['재직 중인 계정이 아님']
[추가확인] 5 junho ['기기 보안 상태 이상 (+40)']
[거부] 6 junho ['해외에서 접속 (+30)', '새벽 접속 (+20)']
[거부] 7 seoyeon ['이 계정에 등록된 기기가 아님']
허용 1 건 / 추가확인 2 건 / 거부 4 건
거부 이유별 건수 {'이 계정에 등록된 기기가 아님': 2, '재직 중인 계정이 아님': 1, '해외에서 접속 (+30)': 1, '새벽 접속 (+20)': 1}
```

- (나) 🔍 거부된 요청 중 필수 조건에서 바로 거부된 것과 점수가 쌓여서 거부된 것은 각각 몇 번 요청이고 이유가 무엇인가요?
  - 쓸 내용: ① 필수 조건으로 거부된 요청 번호와 이유 ② 점수로 거부된 요청 번호와 이유 목록
  - 답: 필수 조건에서 바로 거부된 요청은 3번(등록되지 않은 기기 `NB-7741`), 4번(퇴사한 계정 `dami`), 7번(등록되지 않은 기기 `NB-7741`)입니다. 점수로 거부된 요청은 6번이며, 해외 접속 30점과 새벽 접속 20점이 합쳐 50점이 되어 거부됐습니다. 2번은 대량 조회 30점으로 추가확인, 5번은 기기 보안 상태 이상 40점으로 추가확인됐고 1번은 허용됐습니다.
- (다) 🔍 거부 이유별 건수에서 가장 많은 이유는 무엇이고, 이 숫자는 보안 담당에게 무엇을 알려 주나요?
  - 쓸 내용: ① 가장 많은 이유와 건수 ② 기록으로 확인되는 것과 확인되지 않는 것 ③ 보안 담당이 할 일
  - 답: 가장 많은 이유는 「이 계정에 등록된 기기가 아님」으로 2건입니다. 요청 3번과 7번에서 미등록 기기 `NB-7741`이 사용된 사실은 확인되지만, 누가 시도했는지는 이 결과만으로 알 수 없습니다. 보안 담당은 기기의 소유자를 확인하고 이 기기의 다른 접속 기록도 조사해 필요하면 차단해야 합니다.
- (라) 🔍 등록 기기 · 국내 · 낮 시간에 MFA 까지 한 같은 계정이 20건 미만 조회를 100번 반복하면 이 코드는 어떻게 판정하나요? 왜 그런지, 이를 막으려면 무엇이 필요한지 적어 주세요.
